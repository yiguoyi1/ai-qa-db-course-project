# AskWise Community v0.1.1 · 源码发行版

面向本地部署、课程展示和二次开发的源码发行版，统一在主项目仓库提供下载。包含 Web / FastAPI 后端、Tauri 与 CLI 客户端源码、Oracle 数据库脚本、运行配置及启动说明。

## 下载

在本页 **Assets** 下载：

- `askwise-community-v0.1.1-source.zip`：整理后的源码发行包。
- `askwise-community-v0.1.1-source.zip.sha256`：ZIP 的 SHA-256 校验文件。

解压后从 `README.md` 开始；`SOURCE_MANIFEST.json` 记录来源提交和文件校验值。

GitHub 自动附带的 `Source code (zip)` 和 `Source code (tar.gz)` 是完整仓库快照，与上述精简源码包不同。

## 本次整理

- 下载入口统一到当前主仓库，不再依赖独立发行仓库。
- 提供完整的 Windows 本地初始化步骤，包括分类和种子数据加载。
- 补齐首页引用的宣传图片、视频，避免源码部署时资源缺失。
- 补充 `tzdata` 依赖，修复全新 Windows 环境因缺少 `Asia/Shanghai` 时区数据而无法启动的问题。
- 从指定 Git 提交构建，提供来源清单和 SHA-256，不打包本地配置、真实用户数据及课程报告。
- 保持当前主分支的业务接口与数据库结构不变，未引入新的数据库迁移。

## 使用边界

本包是源码，不是 Windows 安装器；需要自行准备 Python、Docker / Oracle，以及使用 AI 时所需的 DeepSeek Key。不内置数据库镜像、依赖环境或账户凭据。旧演示服务器不作为可用服务提供。

本次发行验证覆盖打包测试、文件完整性、来源一致性、Python 语法与无需数据库的 Web/API 冒烟检查；不代表在全新 Oracle 实例完成了完整业务回归。

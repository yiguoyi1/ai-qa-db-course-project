# 项目测试指南

本文档面向测试同学，用于按当前仓库功能状态执行网页端、接口联动和关键业务回归测试。

最后更新：2026-04-27

## 1. 测试目标

本轮测试目标是确认当前项目可以作为课程设计演示版本稳定运行，重点覆盖：

- 对外产品首页、登录注册、社区首页、问题详情、用户中心、管理员后台。
- 纯社区提问、AI 首答提问、人工回答、采纳答案、收藏、点赞/点踩。
- 评论、楼中楼回复、AI 回答追问会话。
- 分类、标签、搜索、搜索历史、热榜、推荐。
- 用户头像、问题配图、回答配图的上传、展示和删除。
- 用户画像、推荐生成与推荐查询。
- 管理员用户治理、分类管理、标签治理、内容治理和审计日志。
- 企业级 UI/UX 回归，包括响应式、弹窗滚动、卡片、按钮、标签和导航一致性。

## 2. 测试范围

### 2.1 本轮覆盖

- 网页入口：`/`、`/login`、`/home`、`/questions/{question_id}`、`/me`、`/admin`。
- 首页分区：`/home?section=recommend`、`/home?section=hot`。
- FastAPI 后端现有业务接口。
- Oracle 数据库已落地的核心业务能力。
- 原生 HTML、CSS、JavaScript 前端交互。

### 2.2 本轮暂不覆盖

- 评论图片上传。
- 图片审核、隐藏、清理后台。
- 推荐规则人工干预后台。
- 取消采纳答案或采纳历史。
- 标签合并、批量审核。
- 邮件、短信、站内信通知。

### 2.3 状态标记

- ✅：已有测试记录或主链路已完成验证，可继续做回归。
- 待测：近期新增或需要测试同学补测。
- 观察：功能可用但依赖数据量、AI 返回或环境状态，需要记录实际表现。

## 3. 环境准备

执行测试前请确认：

1. Oracle 数据库已启动，schema 和迁移脚本已导入。
2. `.env` 已配置数据库连接、JWT 密钥、DeepSeek API Key 等必填项。
3. 后端服务已启动，推荐地址为 `http://127.0.0.1:8000`。
4. 浏览器建议使用 Chrome、Edge 或 Safari 最新稳定版。
5. 准备至少两个普通用户账号和一个管理员账号。

如果是在旧数据库上继续测试，请确认已按缺失情况导入当前迁移脚本：

```powershell
.\scripts\load-oracle-schema.ps1 -SqlFiles `
  sql/migrations/20260405_add_answers_user_id.sql `
  sql/migrations/20260405_add_answer_comments.sql `
  sql/migrations/20260422_add_media_assets.sql `
  sql/migrations/20260422_add_question_acceptance.sql `
  sql/migrations/20260425_extend_chat_session_for_follow_up.sql `
  sql/migrations/20260427_extend_tag_metadata.sql
```

macOS 或 PowerShell 7 可以使用 `pwsh -File ./scripts/load-oracle-schema.ps1 -SqlFiles 文件1 文件2`，多个文件之间用空格分隔。

常用启动命令：

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

健康检查：

```text
http://127.0.0.1:8000/health
```

主要页面入口：

```text
http://127.0.0.1:8000/
http://127.0.0.1:8000/login
http://127.0.0.1:8000/home
http://127.0.0.1:8000/home?section=recommend
http://127.0.0.1:8000/home?section=hot
http://127.0.0.1:8000/me
http://127.0.0.1:8000/admin
```

管理员账号建议创建方式：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\grant-admin.ps1 -Username <your_username>
```

macOS 或 PowerShell 7 可使用：

```powershell
pwsh -File ./scripts/grant-admin.ps1 -Username <your_username>
```

## 4. 测试账号建议

- 普通用户 A：负责提问、AI 首答、回答、评论、收藏、上传图片、创建 AI 追问。
- 普通用户 B：负责查看 A 的内容、回复、验证跨用户展示和权限隔离。
- 管理员用户：负责后台治理、分类标签维护、内容状态调整和日志查看。

验证多标签页互不干扰时，请在两个标签页分别登录不同账号。当前登录态使用 `sessionStorage`，预期是同一浏览器的不同标签页互不顶号。

## 5. 推荐测试顺序

1. 环境与账号检查。
2. 对外产品首页。
3. 登录、注册、退出、异常登录提示。
4. 全站顶部导航、头像菜单、搜索历史。
5. 首页推荐、热榜、筛选、发帖。
6. 问题详情、回答、收藏、反馈、采纳答案。
7. AI 回答追问会话。
8. 评论与楼中楼回复。
9. 图片、头像和媒体删除。
10. 用户中心、个人资料、历史记录、分页加载。
11. 兴趣画像与推荐生成。
12. 管理员后台。
13. 企业级 UI/UX 与响应式回归。

## 7. 详细测试用例

### 7.1 产品首页

#### TC-LANDING-01 产品首页展示 待测

前置条件：后端服务已启动。

测试步骤：

1. 打开 `http://127.0.0.1:8000/`。
2. 滚动查看产品优势、核心功能、使用场景、热门标签、FAQ 和 Footer。
3. 点击顶部导航锚点。

预期结果：

1. 页面视觉为蓝白科技感产品官网，不应像后台页面。
2. 顶部导航、Hero、产品 Mockup、功能卡片和 FAQ 显示正常。
3. 锚点跳转平滑，移动端菜单可用。

#### TC-LANDING-02 立即体验入口 待测

测试步骤：

1. 在官网首页点击“立即体验”或“立即进入社区”。

预期结果：

1. 页面跳转到 `/login`。
2. 不应出现 404 或本地文件路径。

### 7.2 登录与登录态

#### TC-LOGIN-01 注册新用户 ✅

测试步骤：

1. 进入 `/login`。
2. 切换到注册表单。
3. 输入未使用过的用户名、昵称和密码。
4. 提交注册。

预期结果：

1. 注册成功。
2. 可继续用该账号登录。

#### TC-LOGIN-02 正常登录 ✅

测试步骤：

1. 输入正确用户名和密码。
2. 提交登录。

预期结果：

1. 登录成功并跳转到 `/home`。
2. 页面右上角显示当前用户昵称，若无昵称则显示用户名。
3. 受保护接口可正常调用。

#### TC-LOGIN-03 错误密码提示 ✅

测试步骤：

1. 输入正确用户名和错误密码。
2. 提交登录。

预期结果：

1. 页面提示“用户名或密码不正确”一类用户友好文案。
2. 不应笼统提示网络异常。
3. 不应进入首页。

#### TC-LOGIN-04 服务异常提示 待测

测试步骤：

1. 停止后端服务或断开网络。
2. 在登录页提交登录。

预期结果：

1. 页面提示服务或网络异常。
2. 不应提示用户名或密码错误。

#### TC-LOGIN-05 退出登录 ✅

测试步骤：

1. 登录后点击右上角头像。
2. 点击“退出登录”。

预期结果：

1. 当前标签页登录态被清除。
2. 页面回到登录页或重新要求登录。

#### TC-LOGIN-06 多标签页账号隔离 ✅

测试步骤：

1. 标签页 A 登录普通用户 A。
2. 标签页 B 登录普通用户 B。
3. 分别刷新两个标签页。

预期结果：

1. 标签页 A 仍是用户 A。
2. 标签页 B 仍是用户 B。
3. 两个标签页互不顶号。

## 9. 关键业务口径

测试时请统一以下口径：

1. `POST /api/questions/ask` 会创建问题并触发 AI 首答。
2. `POST /api/questions` 是纯社区发帖。
3. 两类发帖都要求标题、正文和分类有效。
4. 用户可选已有标签、自定义标签；未提供标签时可由 AI 自动识别。
5. 评论挂在回答下，不直接挂在问题下。
6. 评论删除是软删除，显示占位文案是符合预期的。
7. 采纳答案后问题变为 `RESOLVED`，不再接受新回答。
8. 媒体当前覆盖头像、问题配图、回答配图，不覆盖评论图片。
9. 图片存储在 Oracle BLOB 中，前端通过 `public_url` 读取。
10. 推荐依赖行为数据，若账号没有行为，推荐为空是合理情况。
11. AI 追问围绕某条 AI 回答展开，不等同于普通评论区。
12. AI 追问会话可被其他可访问该问题的用户查看，但只有创建者可以继续追问。
13. 用户展示名统一优先使用昵称，没有昵称再使用用户名。
14. 管理后台页面展示中文友好文案，但接口仍使用后端枚举值。
15. UI 优化只改变视觉层，不应改变业务流程。

架构：
ai-qa-db-course-project:    // 项目根目录
    \ app:                  // 源代码
        \ main.py           // 入口文件
        \ web_routes.py     // 前端资源路由
        \ api
            \ router.py     // 路由
            \ routes        // 路由处理函数
            \ auth_deps.py  // jwt解析
            \ deps.py       // 依赖解析（dependency）
        \ schemas           // Model，前后传递承载数据的结构体
        \ core              // 配置文件和错误类型
        \ integration       // 
        \ prompt            // 提示词
        \ repositories      // 持久层
        \ services          // 服务层
        \ web               // 前端页面




router.incloude_router(other_router) 将别的路由挂载在当前路由下面
